# WAVEON Music

A bilingual (Russian / English) music player MVP.

- Plays audio files selected locally by the user.
- Search, track list and next-track controls.
- No third-party commercial music catalog, streaming rights, user accounts or active payments yet.
- WAVEON PRO is a placeholder, not a purchasable subscription.

## Deploy

Deploy this repository as a static site. Publish directory: `.`. No build command needed.

## Legal

Only distribute recordings with appropriate rights and licenses. Never upload copyrighted commercial tracks without authorization.
